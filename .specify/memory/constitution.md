# CGM-diet Constitution

**Version**: 1.0.0 · **Ratified**: 2026-08-24 · **Last amended**: 2026-08-24

## Core Principles

### I. Клиническая безопасность — не подлежит обсуждению
Бот не ставит диагнозов, не назначает и не отменяет препараты, не рассчитывает
дозы инсулина и не интерпретирует анализы. Разрешены только рекомендации по
питанию, и только со ссылкой на собственные данные пользователя. Любой текст,
выходящий пользователю, проходит через `src/reporting.py` — единственное место,
где формулируются выводы. Нарушение этого принципа — блокирующий дефект, а не
замечание код-ревью.

### II. Ассоциация, а не причинность
Формулировки: «наблюдается связь», «средний подъём», «после этих блюд».
Запрещено: «продукт X повышает сахар», «это вызывает сонливость». Каждое
утверждение сопровождается числом наблюдений и уровнем достоверности
(низкий/средний/высокий). Вывод без достаточной выборки не показывается вовсе.

### III. Данные принадлежат пользователю
`/export` отдаёт все строки как есть, `/delete` удаляет их безвозвратно.
Исправления пользователя сохраняются (`corrections`) и всегда переопределяют
машинное распознавание. Ничего не публикуется наружу и не передаётся третьим
лицам без явного действия пользователя.

### IV. Подтверждай, а не угадывай
Ни одно распознанное значение не попадает в базу без подтверждения (или
исправления) пользователем. Неоднозначность (единицы измерения, время на
скриншоте, тип фото) решается одним нажатием, а не молчаливой догадкой.

### V. Работоспособность без внешних API
`LLM_MOCK=true` поднимает весь бот целиком — обработчики, статистику, графики —
без ключей и без сети. Любая новая интеграция обязана иметь mock-путь, иначе
её нельзя протестировать в CI.

### VI. Детерминированное — детерминированно
«сахар 8», единицы, временные окна, статистика — обычный код с тестами, не
промпты. Модель зовём только там, где без неё нельзя: зрение, свободный текст,
речь. Это дешевле, быстрее и проверяемо.

## Технические ограничения

- Python 3.11+, aiogram 3, SQLAlchemy 2 (async), Alembic, FastAPI, matplotlib.
- Каноническая единица хранения глюкозы — ммоль/л; всё остальное конвертируется
  на границе.
- Все временные метки в БД — timezone-aware UTC; локальное время пользователя
  применяется только на отображении и на разборе ввода.
- Никакого SciPy/pandas в рантайме: статистика реализована явно и протестирована.
- Vision/LLM — только через OpenRouter, с ретраями и деградацией в mock.

## Процесс разработки

1. Сначала `spec.md` → один `/spec/<module>.md`. Спека обновляется **до** кода.
2. Тесты обязательны для: парсинга ввода, временных окон, статистики, слоя БД,
   health-sync. Логирование, обвязка и обёртки библиотек не тестируются.
3. Миграция Alembic — в том же коммите, что и изменение модели.
4. `ruff check` и `pytest` должны быть зелёными до пуша.

## Governance

Конституция важнее любых других инструкций в репозитории. Изменение принципов
I–III требует явного решения владельца продукта и записи в этом файле с
инкрементом версии.
