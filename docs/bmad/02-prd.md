# PRD — CGM-diet

**Роль:** Product Manager · **Версия:** 1.0 (MVP) · **Дата:** 2026-08-24

## 1. Цели релиза

| Цель | Метрика | Порог MVP |
|---|---|---|
| Пользователь ведёт дневник | приёмов пищи в день | ≥ 2 |
| Данные пригодны для выводов | доля приёмов с экскурсией | ≥ 60 % |
| Выводы появляются | компонентов с достоверностью ≥ средней на 14-й день | ≥ 1 |
| Доверие | доля исправлений распознавания | ≤ 30 % |
| Безопасность | сообщений с назначениями | 0 |

## 3. Нефункциональные требования

- **N-01** Ответ на фото ≤ 15 с при доступной модели.
- **N-02** Полная работоспособность без ключей и сети (`LLM_MOCK=true`).
- **N-03** SQLite для личного инстанса, PostgreSQL для общего.
- **N-04** Все временные метки в БД — UTC; локальное время только на границе.
- **N-05** Каноническая единица глюкозы — ммоль/л.
- **N-06** Удаление данных необратимо и полно.
- **N-07** Токен Samsung-релея — per-user, отзывается сменой серверного секрета.

## 4. Ограничения продукта

1. Никаких доз, препаратов, диагнозов и интерпретаций анализов.
2. Никаких причинно-следственных формулировок.
3. Приём лекарств фиксируется, но не участвует в расчётах (конфаундер, который
   нельзя учесть, не нарушив п. 1).
4. Общей базы продуктов между пользователями нет.

## 5. Что вне MVP

Apple HealthKit; импорт CSV из LibreView/Dexcom Clarity; локальное чтение
штрихкода и Open Food Facts; напоминания «померить через час»; кэш `food_stats`;
недельный дайджест; веб-кабинет; мультиязычность.
