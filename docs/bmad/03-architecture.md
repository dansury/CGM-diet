# Architecture — CGM-diet

**Роль:** Architect · **Дата:** 2026-08-24

## 1. Обзор

Монолит на Python 3.11: телеграм-бот (aiogram 3) плюс небольшой HTTP-сервис
(FastAPI) для вебхука и приёма активности с телефона. Хранилище — SQLAlchemy 2
(async) поверх SQLite или PostgreSQL. Внешняя зависимость одна — OpenRouter, и
она отключаема.

```
┌──────────┐   photo/text/voice/pdf   ┌────────────────┐
│ Telegram │ ───────────────────────▶ │ handlers/intake│
└──────────┘ ◀─── карточки, графики ── └───────┬────────┘
                                              │ ImagePart / text
                                      ┌───────▼────────┐    ┌──────────────┐
                                      │ vision/        │───▶│ llm/         │
```

## 2. Слои и правила

| Слой | Пакет | Обязанность | Чего не делает |
|---|---|---|---|
| Транспорт | `handlers/` | маршрутизация, FSM, клавиатуры | не считает, не форматирует выводы |
| Распознавание | `vision/`, `llm/` | вызов модели, валидация JSON в дата-классы | не пишет в БД |
| Детерминированный ввод | `ingest/` | текст, единицы, PDF | не зовёт модель |
| Данные | `db/` | ORM и репозиторий | не содержит бизнес-правил вывода |
| Аналитика | `analytics/` | окна, статистика, метрики | не знает про ORM и Telegram |
| Представление | `reporting/`, `charts/` | тексты и картинки | не считает статистику |
| Интеграции | `health/`, `web/` | релей и HTTP | не содержит логики выводов |

Два правила, которые держат систему:

1. **`analytics/` не импортирует ORM.** Работает с `MealLike`, `GlucosePoint`,
   `CheckinLike`, `ActivityBucket`. Поэтому статистику можно тестировать без
   базы, а базу менять без переписывания статистики.
2. **`reporting.py` — единственный источник пользовательских выводов.** Все
   формулировки, дисклеймеры и пороги «что можно сказать» живут в одном файле,
   который можно прочитать целиком за пять минут и проверить на соответствие
   принципам I–II конституции.

## 3. Модель данных

16 таблиц; полное описание — в `spec/data_model.md`.

**Ядро:** `users` → `meals` → `meal_items`; `glucose_readings`;
`wellbeing_checkins` → `checkin_symptoms` → `symptoms`.
**Справочники:** `products` → `product_photos`; `media_files`.
**Контекст:** `weights`, `medications`, `analysis_results`, `activity_samples`.
**Служебные:** `corrections` (аудит правок), `food_stats` (кэш агрегатов).

Соглашения: UTC-aware timestamp; глюкоза в `value_mmol` с сохранением
`unit_input`; нутриенты в граммах; удаление пользователя — явные DELETE по
таблицам (SQLite не гарантирует каскады без PRAGMA).

## 4. Ключевые алгоритмы

**Экскурсия** (`analytics/windows.py`): базовая линия = среднее точек в
[−20 мин; +10 мин] от приёма пищи (при отсутствии — ближайшая точка в ±30 мин);
дельта = максимум в окне минус базовая линия; iAUC — трапеции только над базовой
линией; при попадании другого приёма пищи в [−30 мин; конец окна] экскурсия
помечается contaminated.

**Статистика** (`analytics/stats.py`): группировка по ключу (тег / блюдо /
продукт), t-доверительный интервал среднего, контраст с группой «без этого
ключа», Mann–Whitney U (нормальная аппроксимация с поправкой на связки),
градация достоверности по n / CI / p / величине эффекта.

**Метрики CGM** (`analytics/cgm_metrics.py`): доли времени взвешены по времени,
а не по числу точек; GMI/eA1c/LBGI/HBGI/J-index конвертируют в mg/dL внутри.

## 5. Внешние зависимости и деградация

| Зависимость | Отказ | Поведение |
|---|---|---|
| OpenRouter | 429/5xx | 3 попытки с экспоненциальным бэкоффом, отдельный бэкофф для 429 с учётом `Retry-After` |
| OpenRouter | нет ключа | автоматический `MockClient`, бот полностью работоспособен |
| STT | не настроен | «напишите текстом», данные не теряются |
| PyMuPDF | не установлен | просьба прислать фото страницы |
| БД | недоступна при старте | миграции fail-open, бот стартует, `/health` показывает причину |

## 6. Развёртывание

Multi-stage Docker (venv в builder, non-root в runtime, tini как PID 1).
`entrypoint.sh` прогоняет `alembic upgrade head` с тремя попытками и запускает
бота. `docker-compose.yml` поднимает PostgreSQL + миграции + бота.
Режим по умолчанию — long polling; `BOT_MODE=webhook` включает FastAPI.

## 7. Безопасность

- Секреты только из окружения; `.env` в `.gitignore`.
- Вебхук Telegram проверяет `X-Telegram-Bot-Api-Secret-Token`.
- Релей активности: HMAC-SHA256 от `tg_id` на серверном секрете, сравнение
  через `compare_digest`, идемпотентность по `external_id`, лимит 5000 записей
  на запрос.
- Медиа не хранятся на диске: в БД лежит только `tg_file_id`.
- `/delete` удаляет всё; `/export` отдаёт всё.

## 8. Точки роста

`food_stats` уже в схеме — при росте истории пересчёт `/stats` заменяется на
инкрементальный кэш. `health/` спроектирован платформо-нейтрально, поэтому
Apple HealthKit добавляется без изменения эндпоинта. `llm/` скрыт за протоколом
`LLMClient` — смена провайдера не затрагивает остальной код.
