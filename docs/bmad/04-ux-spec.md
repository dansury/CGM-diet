# UX/UI Specification — CGM-diet

**Роль:** UX Expert · **Дата:** 2026-08-24 · **Платформа:** Telegram

## 1. Принципы интерфейса

1. **Главный сценарий — два нажатия.** Фото → карточка → «✅ Верно».
2. **Ввод в любом виде.** Пользователь не обязан помнить команды и формат.
3. **Ничего не пишется молча.** Каждое распознанное значение подтверждается.
4. **Ошибка исправляется одной строкой,** а не пошаговым мастером.
5. **Пустое состояние объясняет, что сделать,** чтобы оно перестало быть пустым.
6. **Выход есть всегда:** «🗑 Отменить» на каждой карточке.

## 2. Навигация

Постоянная reply-клавиатура из шести кнопок — то, что делается ежедневно:

```
🍽 Записать еду        🩸 Записать сахар
🛒 Проверить продукт   🙂 Самочувствие
📊 Статистика          📈 График
```

Всё остальное — команды: `/today`, `/export`, `/delete`, `/health`,
`/settings`, `/help`. Они же продублированы в меню команд Telegram.

## 3. Ключевые экраны

### 3.1 Онбординг (`/start`)

Одно сообщение, три блока: **что присылать** (с эмодзи-маркерами по типам
ввода), **что бот делает**, **чего бот не делает**. Последний блок обязателен и
идёт до первого взаимодействия — ожидания задаются сразу.

### 3.2 Карточка приёма пищи

```
🍽 Гречка с курицей и овощным салатом
🕒 24.08 13:40
• гречневая каша — 180 г, угл 38 г
• куриная грудка — 120 г, угл 0 г
• салат из огурцов и помидоров — 150 г, угл 5 г

Итого: 443 ккал · Б 46 · Ж 9 · У 43 · клетчатка 7 г
Уверенность распознавания: 72%
Порции оценены по размеру тарелки.

Всё верно?
[✅ Верно]         [✏️ Исправить]
[🕒 Другое время]  [🗑 Отменить]
[🤖 Это не еда]
```

Решения: уверенность показывается всегда (иначе пользователь не понимает, когда
проверять внимательно); «🤖 Это не еда» — страховка от ошибки классификатора;
время видно сразу, потому что именно оно определяет попадание в статистику.

### 3.3 Правка

Одно сообщение с примером формата: `гречка 250, курица 100`. Нутриенты
пересчитываются пропорционально, теги сохраняются, карточка показывается заново.

### 3.4 Показания глюкозы

Список распознанных точек с датой, временем и значением в единицах
пользователя. Кнопки: «✅ Сохранить», «✏️ Исправить», «🔁 Сменить единицы»,
«🗑 Отменить». Кнопка единиц существует потому, что диапазон 18–33 валиден в
обеих шкалах и угадывать нельзя.

### 3.5 Проверка продукта

```
🛒 Проверка продукта
Дымов · Йогурт питьевой клубника
На 100 г: 86 ккал · Б 2.8 · Ж 2.5 · У 12.6
Из них сахаров: 11.9 г
Состав: молоко нормализованное, сахар, пюре клубники…
Метки: добавленный сахар, сладкий напиток

📊 Что говорят ваши данные
• «добавленный сахар»: наблюдалось 9 раз, средний подъём +3.2 ммоль/л
  (🟢 высокая достоверность)

Похоже, этот продукт стоит взять в меньшем объёме или заменить.

[🍽 Я это съел(а)]
[➕ Вторая сторона]  [💾 Только запомнить]
[🗑 Отменить]
```

Ответ всегда опирается на данные пользователя. Если данных нет, так и
говорится — вместе с предложением набрать наблюдений.

### 3.6 Самочувствие

Шаг 1 — оценка, кнопки в столбик с подписями («5 отлично» … «1 очень плохо»),
чтобы полярность шкалы была однозначной. Оценка 5 завершает диалог.

Шаг 2 — симптомы, по два в ряд, из личного глоссария (12 самых частых),
переключаются нажатием (☑️). Внизу: «➕ Другое», «🎤 Голосом», «✅ Готово».
«Готово» без выбора — валидно.

### 3.7 Статистика

Блоки в одном сообщении: рейтинг компонентов → сводка по глюкозе → симптомы →
рекомендации. Под сообщением — переключатели окна (1 ч / 2 ч), типа ключа
(компоненты / блюда) и кнопка графика.

Каждая строка рейтинга: название по-русски, уровень достоверности эмодзи,
n / среднее / медиана / максимум, сравнение с группой «без этого компонента»
и p-value. Внизу — напоминание о том, что это связь, а не причина.

### 3.8 Удаление

Показывает точные количества строк по каждой категории, напоминает про
`/export`, требует явного подтверждения. Порядок кнопок намеренно
«безопасный сверху»: сначала «❌ Нет, оставить», затем «🗑 Да, удалить всё».

## 4. Тон

По-русски, на «вы», без медицинского жаргона и без бодрого коучинга. Числа
вместо оценок. Дисклеймер — там, где даются рекомендации по питанию, и в
онбординге; не в каждом сообщении.

## 5. Доступность и устойчивость

- Эмодзи — только как акцент; смысл всегда продублирован текстом.
- Длинные списки обрезаются (12 показаний, 8 компонентов, 8 ингредиентов).
- Любая ошибка распознавания заканчивается предложением ввести данные текстом.
- Голос — полноценная альтернатива клавиатуре на всех текстовых шагах.
