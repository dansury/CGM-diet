# charts — графики

Matplotlib, backend `Agg`, возврат — сырые байты PNG (handler отдаёт их через
`BufferedInputFile`, без записи на диск). В контейнере обязателен
`MPLCONFIGDIR=/tmp/matplotlib`.

```
render_timeline(points, meals:[(at,label)], title?, checkins:[(at,score)]?) -> bytes
render_ranking(stats:[KeyStats], limit=10, unit_label="ммоль/л") -> bytes
render_wellbeing(series:[(at,score)], symptom_series:{name:[(at,0|1)]}?, title?) -> bytes
```

**timeline** — кривая глюкозы, зелёная полоса целевого диапазона 3.9–10.0,
вертикальные пунктиры приёмов пищи с подписями (обрезка 22 символа), опциональная
вторая ось с оценкой самочувствия 1–5.

**ranking** — горизонтальные бары среднего подъёма по компонентам; цвет по
достоверности (высокая `#c0392b`, средняя `#e67e22`, низкая `#95a5a6`), подпись
`+3.2 (n=9)` у каждого бара. Пустой список даёт корректную картинку
«Недостаточно данных», а не исключение.

**wellbeing** — оценка по времени плюс треугольные маркеры симптомов.

Время на осях подаётся уже в локальной зоне пользователя (`to_local` в
`handlers/reports.py`) — сам модуль часовыми поясами не занимается.
