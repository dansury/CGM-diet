# clinical — что можно и чего нельзя говорить

Единственное место, где рождаются пользовательские выводы, — `src/reporting.py`.

## Запрещено безусловно

- диагнозы и предположения о заболеваниях;
- назначение, отмена, замена препаратов;
- расчёт доз (инсулин в первую очередь);
- интерпретация анализов сверх сравнения с референсом из самого документа;
- причинно-следственные формулировки: «продукт X повышает сахар», «это вызывает
  сонливость», «у вас инсулинорезистентность».

## Разрешено

- рекомендации по питанию, каждая со ссылкой на собственные наблюдения
  пользователя (число наблюдений + средний подъём + группа сравнения);
- описательные метрики глюкозы с указанием общепринятых целей (TIR > 70 %,
  CV < 36 %) — как справка, без оценки состояния;
- пометка «вне референса» на маркерах анализов + «покажите врачу»;
- подсветка значений ниже 3.9 ммоль/л при симптоме (гипогликемию нельзя
  пропустить);
- справка из открытой базы побочных эффектов — как совпадение записей
  пользователя со справочником, всегда с «совпадение по времени — не
  доказательство причины» и «не меняйте приём и дозу самостоятельно».

## Обязательные формулировки

| Вместо | Пишем |
|---|---|
| «повышает сахар» | «наблюдается связь», «после этих блюд средний подъём…» |
| «вызывает сонливость» | «сахар в момент отметки был выше, чем в остальные» |
| «у вас преддиабет» | «показатель вне референса — стоит показать врачу» |
| «примите …» | (ничего; бот не назначает) |
| «препарат вызывает сонливость» | «в справочнике побочных эффектов этот симптом указан для препарата» |
| «сахар выше из-за лекарства» | «приём попал в N из M наблюдений — это контекст, не оценка препарата» |

## API `src/reporting.py`

```
DISCLAIMER ; CONFIDENCE_LABEL{high|medium|low}
format_meal_draft(draft, eaten_at?) -> str
format_product(draft, mode="eaten"|"check") -> str
format_product_verdict(draft, matches:[KeyStats], unit) -> str
format_stats(stats, unit, window, limit=8) -> str
format_recommendations(stats, unit) -> str      # только actionable, максимум 3
format_cgm_summary(summary, unit) -> str
format_symptoms(stats, unit) -> str
format_activity(contrast, unit) -> str
format_labs(draft) -> str
format_medication_draft(draft, taken_at?, applied?) -> str
format_medications(rows, days=30) -> str
format_med_coverage(coverages) -> str | None
format_med_side_effects(links) -> str | None
```

`applied` — блок «Учтено из вашей правки»: пользователь должен видеть, что
корректировка встроена в распознавание, а не что карточка собрана заново.

Пустые состояния объясняют, что нужно сделать, чтобы вывод появился, — они не
извиняются и не молчат.

Тест-стражи:
- `tests/test_pipeline.py::test_reports_mention_the_offender_and_stay_non_causal`
  падает, если в отчёте появится «повышает сахар»;
- `tests/test_meds.py::test_the_side_effect_note_never_claims_a_cause` — если в
  справке по побочкам появится «вызывает».
