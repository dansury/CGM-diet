# wellbeing — самочувствие и глоссарий симптомов

## Поток

1. `/wellbeing` или кнопка «🙂 Самочувствие» → `WellbeingFlow.scoring`,
   пять кнопок с подписями: «5 отлично» … «1 очень плохо».
2. Оценка **5** → сразу сохраняется, диалог закрыт (чувствовать себя хорошо не
   должно стоить дополнительных нажатий).
3. Оценка < 5 → `WellbeingFlow.picking`: до 12 кнопок из личного глоссария по
   две в ряд, переключение нажатием (☑️), плюс «➕ Другое», «🎤 Голосом»,
   «✅ Готово».
4. «Готово» **без выбранных симптомов — валидно**: бывает «просто устал».
5. «Другое» / «Голосом» → `WellbeingFlow.free_text` → `extract_symptoms`
   (модель) → новые метки добавляются в глоссарий и возвращают пользователя к
   кнопкам.

## Динамический глоссарий

```
symptoms(id, user_id, slug, label, hits, is_active, last_used_at)  uq(user_id, slug)
repo.seed_symptoms(user)          # 12 стартовых при регистрации
repo.list_symptoms(user, limit=12) # order by hits desc, id
repo.upsert_symptom(user, label)   # slug = normalize_name(label).replace(" ","_")
```

Нормализация slug обязательна: без неё «сонливость», «Сонливость» и
«сонливость.» станут тремя разными симптомами и статистика развалится.
`hits` инкрементируется при каждом сохранении отметки — самые частые симптомы
всплывают наверх сами.

Стартовый набор: сонливость, потливость, туман в голове, сильный голод, жажда,
сердцебиение, дрожь, головная боль, раздражительность, приливы, слабость,
тошнота.

## Хранение

`wellbeing_checkins(user_id, at, score 1..5, note, source, media_id)` +
`checkin_symptoms(checkin_id, symptom_id, severity?)`.
`source`: `buttons | text | voice`. Самочувствие также извлекается из свободного
текста («самочувствие 3») без модели.

## Аналитика

См. `spec/analytics.md` § Symptoms. Показывается контраст сахара при симптоме
против остальных отметок, доля постпрандиальных случаев и число эпизодов с
сахаром ниже 3.9 ммоль/л. Причины симптома не называются.

## График

`charts.render_wellbeing(series, symptom_series?)` — оценка 1–5 по времени плюс
маркеры симптомов. Это и есть «график сонливости» из ТЗ: сонливость —
обычная метка глоссария, отдельного механизма для неё нет.
