# web — деплой на PHP-хостинг

Спецификация: `../spec/web.md`. Ниже — только шаги деплоя.

## Требования хостинга

PHP ≥ 8.1 (нужен `openssl_pkey_derive` для web push), расширения `pdo_sqlite`,
`curl`, `openssl`. Composer не нужен — весь `web/` самодостаточен, сборки нет.

## Деплой

1. Скопируйте содержимое `web/` целиком в корень (или подкаталог) хостинга —
   обычным FTP/SFTP/файловым менеджером. Никакой сборки не требуется.
2. Убедитесь, что `web/data/` доступна на запись веб-сервером (создание
   `app.db` при первом обращении) — `chmod 775 data` при необходимости.
3. Откройте `https://ваш-домен/admin/` — при первом заходе будет предложено
   задать пароль администратора.
4. В админке заполните: `OPENROUTER_API_KEY` (или `YANDEX_API_KEY` +
   `YANDEX_FOLDER_ID`), модель по умолчанию, `ADMIN_EMAIL` (используется как
   VAPID `subject` для push). Нажмите «Перегенерировать VAPID», если хотите
   включить напоминания.
5. Для напоминаний по расписанию настройте cron хостинга (обычно — в панели
   управления) на вызов раз в час (или как нужно):
   `curl "https://ваш-домен/api/push_send.php?key=<CRON_SECRET>"`
   (ключ — из раздела «Push-уведомления» в админке). Без крона напоминания
   можно рассылать вручную кнопкой «Отправить напоминание сейчас».
6. Проверьте `https://ваш-домен/` (лендинг) и `https://ваш-домен/app/`
   (приложение) — оба должны открыться без ошибок в консоли браузера.

## Обновление LLM-инфраструктуры

`web/lib/vendor/*` — зеркало репозитория `site_yacloud_openrouter`, не
редактируется на месте (`web/lib/vendor/VENDORED_FROM.md`). Чтобы подтянуть
новую версию: скопировать `llm.php`, `config.php`, `settings_store.php`,
`model_catalog.php` из `site_yacloud_openrouter` поверх файлов в
`web/lib/vendor/`, обновить дату/коммит в `VENDORED_FROM.md`, перезадеплоить.

## Иконки PWA

`web/app/icons/*.png` рисует `scripts/gen_app_icons.py` (только стандартная
библиотека, зависимостей нет) — тот же кочан романеско, что и в интерфейсе.
Перегенерировать: `python scripts/gen_app_icons.py`. Размеры и имена файлов
менять не нужно, `manifest.webmanifest` на них уже ссылается.

## Шрифт

`web/assets/fonts/electrolize.woff2` — Electrolize (SIL OFL), тот же
дисплейный шрифт, что на `dansury.github.io`. Лежит в репозитории, снаружи не
подгружается: приложение должно открываться офлайн. Inter для интерфейсного
текста лендинг берёт из Google Fonts, у приложения — системный фолбэк.
